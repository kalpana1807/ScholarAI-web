# 🎓 ScholarAI

ScholarAI is an AI-powered study companion that helps students learn smarter, revise faster, and stay organized.

## ✨ Features

- 🤖 AI Chat Assistant
- 📄 PDF Upload & Analysis
- 📝 AI Notes Generator
- ❓ Quiz & MCQ Generator
- 📚 Flashcards
- 📅 Study Planner
- 🌙 Dark Mode
- 🔒 Secure Authentication
- ☁️ Supabase Database

## 🛠️ Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Supabase

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/kalpana1807/ScholarAI-web.git
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```
